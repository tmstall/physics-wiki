# New chat (Claude Project)

This Project already has the Framework, reader profile, and delivery rules. **Do not paste a prior-chat summary.** The Project + the analysis `.md` files are the memory.

## One paper, one chat

- **New paper** → new chat. Upload the PDF or paste the citation. Run the full framework. Write `incoming\md\YYYY-MM-DD_<id>_<slug>.md` (no `g_` prefix). Mirror to Drive `Technical Papers/Analyses`. Log it. Then stop.
- **Deep dive** → stay in **this** chat. Point at that analysis file + PDF. Append Q&A into the same file. Do not recap other papers.
- **Done** → end the chat. Next paper is a new chat.

## Do not

- Do not seed this chat with completed papers or a long session dump.
- Do not run Cowork `copy` here. `copy` is a separate Cowork session (Physics-Wiki connected). `ingest` is Build.
- Do not mark anything ingested without explicit user confirmation.
- Do not write placeholders; file writes carry the full document.
- Do not surface or remember incidental confidential files that appear in Drive search.

## Forced cutover only

If this paper is unfinished and the chat must die, leave a **10-line** handoff: title, DOI/arXiv, inbox filename, posture/lite, what is written, what is still open. No other papers.
