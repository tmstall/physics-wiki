# Android quickstart — Physics Wiki Coordinator

1. Open **Grok app** → Bot **Physics Wiki Coordinator**.
2. Paste DOI, arXiv link, PDF, or title (“analyze this…”).
3. When asked, pick mode:
   - **A** — Claude only (you can finish on the phone)
   - **B** — Grok Build only (kickoff queued for desktop)
   - **C** — Both
   - **D** — Compare (need both analyses first)
4. **Claude path:** paste the Claude kickoff into Claude → save analysis as  
   `incoming/md/YYYY-MM-DD_….md` (connected folder) or sync later.
5. **Grok path:** on PC, open Physics-Wiki in **Grok Build**, paste Build kickoff, say `analyze`.
6. When Bot says inbox ≥5 (or you have enough files): desktop Cowork → **`copy`** → Build → **`ingest`**.
7. Reading finished analyses: Obsidian → Google Drive `Technical Papers/Analyses` (Reading view for math).

**Bot does not write the paper analysis.** It only coordinates.
