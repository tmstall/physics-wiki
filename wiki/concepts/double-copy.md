# Double Copy

**One-line summary:** A dictionary relating gauge-theory quantities to gravity — classically, Kerr-Schild gravity often looks like the “square” of a Maxwell field sharing the same null direction.

## Physical picture

If \(A_\mu = \phi k_\mu\), gravity can use \(h_{\mu\nu} \propto \phi k_\mu k_\nu\). [[hawking-radiation-charge-shell]] runs the map backward: EM charge shell ↔ Vaidya mass shell; flat-space scattering thermality ↔ Hawking temperature.
