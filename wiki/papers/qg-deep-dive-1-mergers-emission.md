# QG Deep Dive 1: Beyond-GR Merger–Ringdown Waveforms

**One-line summary:** Analytical EFT / large-mass-ratio framework computes how black-hole binary merger and ringdown waveforms change when GR is wrong — covering classes of theories without a supercomputer campaign per model.

## Key claims and results

- Methods paper: first-principles path to merger–ringdown in effective-field-theory extensions of GR (small secondary / large mass-ratio regime).
- Goal: LIGO/Virgo/KAGRA and LISA need not only GR templates but controlled beyond-GR predictions at merger.

## Physical intuition

Inspiral is post-Newtonian; ringdown is black-hole spectroscopy. The messy join — merger — is where most alternative-gravity numerics give up. This program builds an analytical “compiler” for beyond-GR corrections so each theory is not a new months-long simulation job. Think of it as generating test vectors for a whole ISA family instead of writing a microcode test for every chip.
