# QG Deep Dive 4: de Sitter Holography

**One-line summary:** Positive Λ / de Sitter space replaces AdS’s shared conformal boundary with observer-dependent cosmological horizons — holography and thermodynamics must be rebuilt without AdS crutches.

## Key claims and results

- Geometry: de Sitter radius $L_{dS}=\sqrt{3/\Lambda}$; static patch with cosmological horizon.
- Cosmological horizon is thermodynamic (temperature/entropy analogs of black holes).
- No shared asymptotic boundary like AdS — observer-centric holography proposals.
- Connects accelerating-universe observations to quantum-gravity dictionary gaps.

## Physical intuition

AdS is a box with walls you can put a dual theory on. de Sitter is an expanding bubble where every observer has a personal horizon and no common wall. Black-hole thermodynamics taught us horizons = entropy; cosmology hands every observer such a horizon for free. The hard problem is writing a holographic code without a shared boundary — like designing a network protocol when every node only sees its own light cone.
